# Atlas

O Atlas é um projeto acadêmico criado para apresentar diferentes países e temas em um único site.

A página inicial possui um mapa-múndi como referência visual e uma lista com os países participantes. O acesso aos conteúdos é feito pelos nomes dos países apresentados abaixo do mapa.

Cada integrante ficou responsável por um país e por um tema diferente. Por isso, as páginas possuem estruturas próprias, mas continuam ligadas pela navegação do Atlas.

## Países e temas

- México — Música e Mitologia
- Grécia — Gastronomia
- Egito — Monumentos Históricos
- Itália — História
- Canadá — Natureza
- Alemanha — Guerras e Impactos Políticos
- Suíça — Turismo e Oportunidades Profissionais
- Austrália — Biodiversidade
- Japão — Evolução das Artes Visuais
- França — Museus, Artistas e Moda

## Organização

O arquivo `index.html` é a página inicial.

As páginas de cada país estão na pasta `paginas`.

As imagens estão na pasta `img`, separadas por país.


## Outras páginas

- `sobre.html` — explicação geral do projeto.
- `creditos.html` — integrantes e divisão das páginas.
